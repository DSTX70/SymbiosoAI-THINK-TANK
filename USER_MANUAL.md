## Overview

**SymbiosoAi ThinkTank** is an enterprise-grade collaborative intelligence platform that leverages multiple AI agents to conduct structured debates and generate consensus-driven insights. The platform orchestrates debates between specialized AI agents (Analyst, Critic, Synthesizer, and Domain Expert) to produce well-reasoned conclusions, identify dissenting viewpoints, and highlight unresolved questions.

### Key Features ✨
- **Three Progressive Complexity Levels**: Simple, Guided, and Expert modes
- **18+ Specialized Domain Experts**: Legal, Medical, Financial, Technology, Business, and more
- **Real-time Team Collaboration**: Live session sharing, team chat, workspace synchronization
- **Interactive Fact-Checking**: Configurable verification depth and source requirements
- **Visual Journey Timeline**: Step-by-step progress tracking with timestamps
- **Template Library**: Pre-built analysis templates with ratings and categories
- **Role-Based Permission System**: Owner, Admin, Member, and Viewer roles

## Multi-Agent AI System

### Core AI Agents

#### 🧠 **Analyst**
- Provides data-driven analytical perspectives
- Evidence-based reasoning approach
- Focuses on facts and objective analysis

#### 🤔 **Critic**
- Challenges assumptions and presents alternative viewpoints
- Devil's advocate role in debates
- Identifies potential flaws and counterarguments

#### 🔗 **Synthesizer**
- Builds consensus from different perspectives
- Integrates and reconciles viewpoints
- Creates coherent conclusions from debate rounds

#### 👨‍💼 **Domain Expert**
- Specialized knowledge in specific fields
- Industry best practices and standards
- Context-aware recommendations

### Debate Process
1. **Question Input**: User provides topic or question for analysis
2. **Agent Selection**: Choose relevant domain experts
3. **Multi-Round Debate**: Agents build upon each other's contributions
4. **Consensus Building**: Synthesizer creates final recommendations
5. **Result Presentation**: Clear conclusions with dissenting viewpoints

## Troubleshooting

### Common Issues

#### Authentication Problems
**Issue**: Unable to log in or frequent logouts
**Solution**: 
- Clear browser cache and cookies
- Check Replit authentication status
- Verify environment variables are properly configured

#### WebSocket Connection Issues
**Issue**: Real-time features not working (chat, sync)
**Solution**:
- Check network connection
- Verify WebSocket support in browser
- Refresh page to reestablish connection

#### Debate Not Starting
**Issue**: AI agents not responding or debate stuck
**Solution**:
- Verify OpenAI API key configuration
- Check API rate limits and quotas
- Try simplifying the question or topic
- Contact support if issues persist

#### Template Loading Issues
**Issue**: Templates not loading or missing content
**Solution**:
- Check database connection
- Verify template permissions
- Refresh template library
- Report corrupted templates to administrators

### Performance Optimization
- **Browser Requirements**: Modern browsers with JavaScript enabled
- **Network**: Stable internet connection for real-time features
- **Device**: Desktop/laptop recommended for Expert mode
- **Memory**: Sufficient RAM for multiple tabs and real-time sync
