# SymbiosoAi — Sprint 1 Handoff Package
**Date:** 2025-09-13

This package contains drop‑in code scaffolds and configuration to deliver Sprint 1 scope:

- **Job queue + progress streaming (SSE)**
- **Auth adapter scaffold + demo‑off in production**
- **“Why Transfer?” panel (UX)**
- **Baseline DLP checks on exports**

> Target stack: Node/Express + TypeScript on backend, React/TS frontend. Redis (Upstash or managed) for BullMQ queue.

---

## 0) Quick Start (Replit)
1. Add environment secrets:
   - `REDIS_URL` = your Redis connection URL
   - `REDIS_PASSWORD` = your Redis password (if applicable)
   - `DEMO_LOGIN_ENABLED` = `false` (in production)
   - `OIDC_ISSUER`, `OIDC_CLIENT_ID`, `OIDC_CLIENT_SECRET`, `OIDC_REDIRECT_URI` for SSO (if available)
2. Install new deps (backend & frontend workspaces as applicable):
   ```bash
   npm i bullmq ioredis express-rate-limit helmet zod
   ```
3. Wire the new routes/middleware into your existing Express app (see code comments).
4. Frontend: import the new components where noted and pass the proper props.
5. Run migrations in `scripts/db/migrations` if you use SQL (adapt to Drizzle as needed).

## 1) Scope & Owners
- **Forge:** Queue + worker + SSE endpoints; DB logs.  
- **CodeBlock:** UI error boundaries, ProgressOverlay, ExportDLPGuard.  
- **Lume:** Content + UX for “Why Transfer?” panel and copy.  
- **LexiCode:** Auth adapter scaffold; `DEMO_LOGIN_ENABLED` gate; secrets.  
- **Sentinel:** DLP policy baseline and headers.  
- **Navi:** Definition of Done; QA matrix.  
- **Ledger/River:** Messaging and perceived‑value checks (observability hooks can be added Sprint 2).

---

## 2) Definition of Done (Sprint 1)
- Enqueued debate/brainstorm runs **do not** tie up request threads.
- **SSE** exposes progress for a given `jobId`; UI shows % and stage.
- **Demo login is disabled** when `DEMO_LOGIN_ENABLED=false`.
- Exports pass **DLP check** (deny P0 patterns), set `Content-Disposition`, and sanitize filenames.
- **Unit/E2E** happy path for: create job → stream progress → show “Why Transfer?” → export with DLP pass.
- Security headers via `helmet` with CSP/HSTS enabled.
