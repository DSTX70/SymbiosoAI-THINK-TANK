## Quick Start (on Replit)
1) **Import `handoff/` into your server and web workspaces.**
2) Set secrets (Project → Secrets):
   - `REDIS_URL`, `REDIS_PASSWORD` (if any)
   - `DEMO_LOGIN_ENABLED=false` (prod)
   - (optional SSO) `OIDC_ISSUER`, `OIDC_CLIENT_ID`, `OIDC_CLIENT_SECRET`, `OIDC_REDIRECT_URI`
3) From your server workspace, wire per `handoff/backend/WIRE_NOTES.ts`:
   - Start worker at boot: `startDebateWorker()`
   - `app.use(demoGate)` and `app.use(helmet())`
   - Mount `/api/debates` and `/api/export` routes
4) **Run API tests:**
   ```bash
   cd tests-api
   npm i
   BASE_URL=http://localhost:3000 npm run test:sprint1
   ```
5) **Run UI tests:**
   ```bash
   cd ../tests-ui-playwright
   npm i
   npx playwright install --with-deps
   BASE_URL=http://localhost:3000 npx playwright test
   ```
