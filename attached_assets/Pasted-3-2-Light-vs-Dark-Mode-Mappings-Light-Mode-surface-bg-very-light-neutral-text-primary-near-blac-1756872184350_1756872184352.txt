3.2 Light vs Dark Mode Mappings

Light Mode

surface.bg: very-light neutral

text.primary: near-black

text.secondary: slate/graphite mid-tone

brand.accent.500: primary blue family

Borders: low-contrast cool-gray

Dark Mode

surface.bg: deep graphite/ink blend

text.primary: off-white

text.secondary: cool gray

brand.accent.500: same hue; ensure 3:1 contrast over surfaces

Borders: subtle cool-gray (alpha-based)

3.3 Tints & Shades (Scale)

Define 50, 100, 200 … 900 steps for brand.accent, neutral, and graphite.
Usage:

50–200: backgrounds, states (hover), large data viz fills

300–600: links, icons, brand flourishes

700–900: emphasis text on light; shadows

3.4 Gradients

gradient.hero: subtle top-to-bottom neutral blend used in hero and brand boards.

gradient.ring: used for concentric ring motif; alpha-aware; never used behind dense text.

3.5 Accessibility

Body text 4.5:1 contrast; large headings 3:1.

Disabled states convey meaning beyond color (opacity + pattern or label).

4) Typography
4.1 Typefaces

Headings: Montserrat — primary weight: Bold (SemiBold for H3+)

Body/UI: Inter — weights: Regular, Medium

Install exact TTF/OTF files in design + build pipelines.

4.2 Web Scale (rem)

Display: 4.5rem / 1.15

H1: 3.0rem / 1.2

H2: 2.0rem / 1.25

H3: 1.5rem / 1.3

Lead: 1.25rem / 1.6

Body: 1.0rem / 1.6

Caption: 0.8125rem / 1.4

4.3 Print Scale (pt)

Display 64, H1 48, H2 32, H3 24, Lead 12–14, Body 10–11, Caption 8–9.

4.4 Usage Rules

Headings: Montserrat Bold; sentence-case; tight but readable tracking.

Body: Inter Regular; Medium for subheads/labels.

Code/mono (if needed): system-mono; size = Body −1 step.

4.5 Do/Don’t

Don’t mix additional display faces.

Don’t center long paragraphs.

Don’t apply faux bold/italic (use real weights).

5) Iconography & Motifs
5.1 O-Loop Symbol

Dual-arrow circular “O” used in the wordmark and as a standalone icon.

Stroke/shape: clean geometric ring; arrowheads symmetrical; rotation feels balanced.

Color: inherits one-color of the lockup or brand accent for hero only.

5.2 System Icons

Style: 1.75 px stroke (scales with 16-px grid), rounded joins/caps, geometric.

Color: text.secondary by default; brand.accent.500 on interactive hover.

5.3 Motifs

Concentric Rings: soft, alpha-layered; thickness 20–28 px at 1920×1080; never behind dense copy.

Subtle Grid/Dots: 8-px grid; alpha 6–14%; used for depth, not decoration.

6) Motion & Effects
6.1 Easing & Durations

Standard: cubic-bezier(0.2, 0.7, 0.0, 1.0)

Durations: 120–180 ms (UI), 240–360 ms (panels), 600 ms (hero motifs)

6.2 Hero Ring

Gentle radial glow/pulse (opacity 0 → 12% → 0, 6–8 s loop), no lateral motion.

6.3 Interaction States

Hover: +4% brightness or accent.400.

Pressed: accent.600 and 1 px inset shadow.

Focus: focus.ring 2 px outside element (AA compliant).

6.4 Respects Reduce Motion

Disable nonessential animation when prefers-reduced-motion is set.
